Возможности

Всё нужное — уже внутри

Никаких серых окон Chrome: история, пароли и загрузки нарисованы заново в стиле Material You.

fast_rewind

Rewind — машина времени

Crumb сохраняет снимки страниц. Откройте, как сайт выглядел вчера, посмотрите, что изменилось, следите за ценой или новостью — придёт уведомление. Ищите по всему, что когда-либо видели.

palette

Цвета из обоев

Палитра Material You строится из ваших обоев Windows и меняется вместе с ними.

key

Свои пароли

Предлагает сохранить пароль и подставляет его. Зашифровано Windows, показать — после Windows Hello.

history

История и подсказки

Посещения по дням, поиск, подсказки прямо в адресной строке.

tab_recent

Вкладки вернутся

После перезапуска или сбоя все вкладки и группы на месте. Сбоку или сверху — как удобно.

download

Загрузки рядом

Маленькое окно загрузок под кнопкой: прогресс, «Открыть файл», значки файлов из Windows.

extension

Расширения Chrome

Ставьте что угодно из Chrome Web Store — работает как в Chrome.

sync

Аккаунт через GitHub

Настройки, домашняя страница и расширения на всех компьютерах. Зашифровано вашим паролем.

find_in_page

Поиск по странице

Ctrl+F — «3 из 17», стрелки, учёт регистра.

cookie

Печеньки везде

Каждая кнопка — печенька: крутится, пружинит, а форму и анимации можно настроить.

Установка

Три шага — и готово

Установщик сам обновит старую версию и сохранит все настройки.

1

Скачайте

Файл Crumb-Setup.exe — около 170 МБ.

2

Запустите

Нажмите «Установить». Права администратора не нужны.

3

Пользуйтесь

Crumb предложит стать браузером по умолчанию — по желанию.

shield Установщик пока не подписан, поэтому Windows SmartScreen может предупредить. Нажмите «Подробнее» → «Выполнить в любом случае». Исходный код открыт на GitHub.
